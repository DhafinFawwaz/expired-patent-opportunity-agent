# Maintenance fee events sample

50 synthetic lines in the fixed-width layout of the USPTO `MaintFeeEvents` file (2018 documentation: patent number in columns 1 to 13, application 15 to 22, entity 24, filing date 26 to 33, grant date 35 to 42, event date 44 to 51, event code 53 to 57, CRLF line ends). The patent numbers in the first twelve lines match the synthetic fixtures; the rest are random. None of it is real data. The real file needs a USPTO Open Data Portal key, which this project does not have.
